Датасет Nottingham Music Dataset для обучения модели берётся с Github:
https://github.com/jukedeck/nottingham-dataset

Ссылка для скачивания:
https://github.com/jukedeck/nottingham-dataset/archive/refs/heads/master.zip

Датасет содержит 3 папки:
1) ABC-cleaned, ABC-original - папки с текстовыми файлами, в которых хранятся ноты аккорды, извлеченные из файлов .mid
2) MIDI - папка с изначальными файлами .mid, она то нам и нужна
