# MIDI Melody Generation with Deep Learning

Проект по генерации музыкальных последовательностей в формате MIDI с использованием нейронных сетей. Система анализирует структуру существующих мелодий и создает новые композиции, сохраняя музыкальную логику (ритм, тональность, гармонию).

## 📌 Описание проекта
Данный проект исследует возможности рекуррентных нейронных сетей (RNN) в творческих задачах. Модель обучается на массиве MIDI-файлов, извлекает из них информацию о нотах, аккордах и длительностях, а затем генерирует уникальные продолжения на основе случайной "затравки" (seed sequence).

## 🚀 Технологический стек
* **Язык:** Python 3.10+
* **Deep Learning:** PyTorch (или TensorFlow/Keras)
* **Обработка музыки:** `music21`, `mido`
* **Анализ данных:** `numpy`, `matplotlib`

## 📂 Структура проекта
* `data/` — папка с исходными MIDI-файлами для обучения.
* `preprocess.py` — скрипт для конвертации MIDI в числовые последовательности.
* `model.py` — архитектура нейронной сети.
* `train.py` — скрипт обучения модели и сохранения весов.
* `generate.py` — скрипт генерации новой музыки по обученным весам.
* `output/` — результаты работы модели в формате `.mid`.

## 🛠 Архитектура модели
В основе проекта лежит архитектура **LSTM (Long Short-Term Memory)**, которая отлично справляется с запоминанием долгосрочных зависимостей в музыке:
1. **Embedding Layer:** преобразует ноты в векторы фиксированной размерности.
2. **LSTM Layers:** несколько слоев (256-512 узлов) с Dropout для предотвращения переобучения.
3. **Dense Layer (Softmax):** выходной слой, предсказывающий следующую ноту из словаря доступных символов.
