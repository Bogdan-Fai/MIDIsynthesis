# Руководство по использованию MIDIsynthesis

## Быстрый старт

### 1. Генерация музыки

```bash
# Базовая генерация
python main.py generate

# Генерация с seed для воспроизводимости
python main.py generate --seed 42

# Генерация с другими параметрами
python main.py generate --seed 123 --temperature 0.8 --top_k 20
```

### 2. Воспроизведение сгенерированной музыки

Сгенерированные MIDI файлы сохраняются в папке `Data/outputs/` с именами вида `generated_YYYYMMDD_HHMMSS.mid`.

#### Вариант 1: Использование встроенного проигрывателя

```bash
# Воспроизвести последний сгенерированный файл
python main.py last

# ИЛИ укажите конкретный файл
python -c "from Services.midi_service import play_midi; play_midi('Data/outputs/generated_20260428_185950.mid')"
```

#### Вариант 2: Использование внешнего проигрывателя

```bash
# На Windows
start Data\outputs\generated_20260428_185950.mid

# На Mac/Linux
# Используйте ваш любимый MIDI проигрыватель, например:
timidity Data/outputs/generated_20260428_185950.mid
```

### 3. Просмотр списка сгенерированных файлов

```bash
# На Windows
dir Data\outputs\*.mid

# На Mac/Linux
ls Data/outputs/*.mid
```

## Решение проблем

### Ошибка: "No file 'Data/outputs/generated.mid' found"

Эта ошибка возникает, когда команда `python main.py last` не может найти файл с именем `generated.mid`. Это происходит потому, что:

1. Сгенерированные файлы имеют временные метки в именах
2. Нужно использовать конкретное имя файла или изменить код

**Решения:**

1. **Используйте конкретное имя файла**:
   ```bash
   python -c "from Services.midi_service import play_midi; play_midi('Data/outputs/generated_20260428_185950.mid')"
   ```

2. **Откройте файл вручную**:
   ```bash
   start Data\outputs\generated_20260428_185950.mid
   ```

3. **Или измените код** (в файле `main.py`):
   ```python
   # Замените строку 57:
   # play_midi("Data/outputs/generated.mid")
   # на:
   play_midi("Data/outputs/generated_20260428_185950.mid")  # или используйте последний файл
   ```

## Параметры генерации

Вы можете настроить генерацию с помощью следующих параметров:

- `--seed`: Seed для воспроизводимости (например, `--seed 42`)
- `--temperature`: Температура генерации (0.1-2.0, по умолчанию 0.9)
- `--top_k`: Параметр top-k sampling (по умолчанию 16)
- `--max_new_tokens`: Максимальное количество токенов для генерации (по умолчанию 256)

Пример:
```bash
python main.py generate --seed 42 --temperature 0.8 --top_k 20 --max_new_tokens 512
```

## Технические детали

- **Модель**: Transformer модель для генерации MIDI музыки
- **Формат токенов**: Ноты в формате `NOTE_DURATION` (например, `C4_0.5`)
- **Аккорды**: Аккорды в формате `NOTE1_NOTE2_NOTE3_DURATION` (например, `C4_E4_G4_0.5`)
- **Словарь**: Файл `Data/vocab.json` содержит все доступные токены

## Улучшение качества генерации

Для получения лучших результатов:

1. **Используйте разные seed**: Экспериментируйте с разными значениями `--seed`
2. **Настраивайте температуру**: Более низкая температура (0.5-0.8) дает более предсказуемые результаты
3. **Увеличьте top_k**: Более высокие значения (30-50) дают более разнообразные результаты
4. **Генерируйте больше токенов**: Увеличьте `--max_new_tokens` для более длинных мелодий

## Часто задаваемые вопросы

**Q: Почему моя мелодия звучит монотонно?**
A: Это может происходить, если модель генерирует много неизвестных токенов. Попробуйте:
- Использовать другой seed
- Изменить параметры температуры и top_k
- Убедиться, что у вас последний vocab.json

**Q: Как воспроизвести MIDI файл на Windows?**
A: Вы можете:
1. Дважды кликнуть на файл .mid в Проводнике
2. Использовать команду `start file.mid`
3. Установить специализированный проигрыватель (например, VLC, Windows Media Player)

**Q: Можно ли экспортировать в другие форматы?**
A: Да, вы можете конвертировать MIDI в другие форматы с помощью инструментов как:
- `timidity file.mid -Ow -o file.wav` (для WAV)
- `ffmpeg -i file.mid -c:a libmp3lame file.mp3` (для MP3)
